  3. 3

.github/workflows/skillcheck.yml

name: SkillCheck
on: [pull_request]
permissions:
  contents: read
jobs:
  verify:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: sixscripts-ai/SkillCheck@v1
        with:
          path: .
          config: skillcheck.config.json
          mode: auto

Product boundary

Evidence, not theater.

SkillCheck makes static risks and release requirements inspectable without pretending static analysis proves runtime safety.

01

Scan the package

Inspect SKILL.md, scripts, manifests, workflows, environment references, symlinks, and install hooks.

02

Bind the result

Create stable package and policy fingerprints so stale evidence cannot authorize a changed draft.

03

Attach runtime proof

Use evaluations and sandbox evidence to satisfy the full release gate outside this static browser scanner.

04

Block regressions

Compare base and head reports to isolate newly introduced findings and permission expansion.

Static-analysis boundary

SkillCheck does not execute uploaded code, guarantee the absence of malicious behavior, replace sandboxing, or eliminate human review.
